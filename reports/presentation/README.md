# Presentation assets

Этот каталог предназначен для финального отобранного набора материалов к защите.

Сюда попадают только уже проверенные графики, таблицы и иные визуальные assets, которые ссылаются на конкретный Stage/версию и подтверждаются `reports/summary/` и соответствующим notebook.

Каталог не заменяет полный исследовательский след в `reports/generated/`, `reports/figures/` и `reports/summary/`; это только curated-набор для итоговой презентации.
