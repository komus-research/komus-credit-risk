# Generated research artifacts

Здесь хранятся machine-readable артефакты проверенных запусков, если они нужны для воспроизводимости, повторного анализа или следующего исследовательского Stage.

Примеры:

- агрегированные JSON/CSV;
- importance/diagnostic tables;
- OOF/diagnostic checkpoints `.npz`;
- metadata и experiment manifests.

Имена должны по возможности содержать Stage и версию. Временные файлы, caches и logs сюда не складываются.
