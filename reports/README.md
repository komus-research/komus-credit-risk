# Research reports

Каталог `reports/` хранит проверяемые результаты исследования, которые должны пережить локальную машину и быть доступны для повторного анализа, итогового отчёта и презентации.

## Структура

- `summary/` — компактные machine-readable summaries каждого Stage.
- `generated/` — вычислительные артефакты: JSON/CSV/NPZ, diagnostics, OOF/checkpoints и metadata, если они нужны для воспроизводимости или следующего Stage.
- `figures/` — графики и визуальные таблицы, поддерживающие исследовательские выводы.
- `presentation/` — отобранные материалы непосредственно для итоговой защиты.

Все четыре каталога разрешено хранить в Git. `reports/` нельзя целиком добавлять в `.gitignore`.

Тяжёлые модели, raw dataset, caches, logs и временные файлы к этому слою не относятся.

Если позже появляются действительно чувствительные данные, правило для них сначала явно фиксируется в `.gitignore` и документации, и только затем продолжается работа с Git.

Подробный исследовательский контракт: `docs/RESEARCH_RECORD.md`.
