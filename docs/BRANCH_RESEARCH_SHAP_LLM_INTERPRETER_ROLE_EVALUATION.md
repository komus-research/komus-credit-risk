# Проверка ролевых LLM-объяснений

Дата проверки: 27.09.2026. Ветка: `research/shap-llm-interpreter`. Модель: `gpt-5.4-mini`.

## Что проверялось

Четыре роли прошли через тот же прикладной путь, который использует Streamlit: `ResultInterpreterService → REDACTED_V1 → OpenAI Responses API`. Для проверки использован синтетический локальный SHAP-пример с вероятностью `0.731` и пятью факторами. Реальные ИНН и данные проекта во внешний API не передавались.

Переданный провайдеру payload содержал только:

- роль получателя;
- уже рассчитанную вероятность;
- обозначение пространства SHAP `raw_margin`;
- пять первых факторов: технические и доверенные отображаемые названия, описания, SHAP-вклад и ранг.

В payload отсутствовали ИНН, `row_id`, исходные значения признаков, `base_value`, raw model output и полная provenance-информация. Использовался `store=false`. Контракт `REDACTED_V1`, privacy boundary, расчёт вероятности и устройство LLM-интеграции не менялись.

## Уточнение промпта по результату первой проверки

В первом ответе для менеджера вероятность `0.731` была названа «скорее повышенной», хотя утверждённый порог не передавался. В общий системный промпт добавлено прямое правило: без явно переданного утверждённого порога нельзя называть вероятность высокой, низкой, повышенной, приемлемой или неприемлемой и нельзя присваивать ей категорию риска. После этого выполнен повторный прогон всех четырёх ролей.

## Финальные примеры

### Менеджер по продажам

> Модель оценила вероятность на уровне 0.731. Сильнее всего оценку вверх сдвинула **Долговая нагрузка**, затем **Динамика выручки**. Вниз оценку заметнее всего подтолкнула **Динамика капитала**, а также немного — **Ликвидность**; по признаку **Q_X17_norm** предметный смысл не задан. Это объяснение модели, а не самостоятельное кредитное решение.

Оценка: краткий нетехнический ответ; направления факторов сохранены; порог и бизнес-решение не выдуманы.

### Кредитный контролёр

> Вероятность по модели: **0.731**.
>
> **Повышают model score положительного класса:** долговая нагрузка (`+0.82`), динамика выручки (`+0.31`) и технический признак `Q_X17_norm` (`+0.11`), для которого предметный смысл не задан.
>
> **Снижают model score положительного класса:** динамика капитала (`-0.55`) и ликвидность (`-0.18`).
>
> SHAP отражает поведение модели и вклад признаков в score, но не доказывает причинность. Без утверждённого порога нельзя делать выводы об одобрении/отказе или оценивать вероятность как высокую/низкую.

Оценка: вероятность и направления влияния переданы точно; факты отделены от ограничений; отсутствующее описание отмечено явно.

### Юрист

> Результат модели: **probability = 0.731**. Это значение рассчитано моделью. Перечисленные значения являются локальными SHAP-вкладами: положительные повышали model score положительного класса, отрицательные снижали его. Для `Q_X17_norm` предметное описание отсутствует, поэтому приведено только техническое имя. SHAP не устанавливает причинность и не является юридическим или кредитным решением; дополнительные факты, которых нет в payload, не добавлены.

Оценка: корректно обозначено происхождение результата и юридические ограничения; нормативных выводов нет.

### Информационная безопасность

> Модель выдала `probability = 0.731`. В payload присутствуют результат модели, обозначение пространства SHAP, роль получателя и пять топ-признаков с SHAP-вкладами. Идентификатор организации, `row identity` и raw feature values в payload отсутствуют.

Оценка: перечислены только фактически переданные категории; утверждений о retention или Zero Data Retention нет.

## Итоговая оценка качества

| Критерий | Результат |
| --- | --- |
| Вероятность не пересчитана и не изменена | Пройдено во всех четырёх ответах |
| Знаки и порядок основных SHAP-факторов | Пройдены |
| Нет причинных утверждений | Пройдено |
| Нет решения «одобрить/отказать» и вымышленного порога | Пройдено после уточнения общего промпта |
| Неописанный признак не получил вымышленный смысл | Пройдено |
| Роли дают различающиеся по назначению ответы | Пройдено |
| Privacy boundary соответствует `REDACTED_V1` | Пройдено; проверено также автоматическим сквозным тестом |

LLM-ответ остаётся вероятностно генерируемым текстом, поэтому эти примеры не являются гарантией каждого будущего ответа. Для эксплуатации целесообразны регулярные regression/eval-наборы с автоматическими и экспертными критериями.

Вместе с первоначальными четырьмя диагностическими вызовами вся проверка из восьми запросов дала верхнюю оценку около `$0.0138`.
